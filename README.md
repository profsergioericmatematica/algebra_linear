# 📐 Álgebra Linear Aplicada

Este repositório é destinado ao estudo e implementação de conceitos de **Álgebra Linear**. O foco principal é a visualização de conceitos abstratos e a aplicação prática em computação e análise de dados.

---

## 📑 Conteúdo Abordado

O projeto explora os pilares fundamentais da disciplina:

* **Matrizes e Sistemas Lineares:** Operações fundamentais, escalonamento e resolução de sistemas.
* **Espaços Vetoriais:** Vetores, base, dimensão e transformações lineares.
* **Determinantes e Autovalores/Autovetores:** Aplicações em diagonalização e transformações geométricas.
* **Aplicações Práticas:** Uso da Álgebra Linear em Computação Gráfica e Ciência de Dados.

## 🚀 Funcionalidades (Scripts & Ferramentas)

Este repositório contém scripts (JavaScript/HTML) voltados para:
1.  **Calculadora de Matrizes:** Soma, subtração e multiplicação de matrizes de diferentes ordens.
2.  **Visualizador de Vetores:** Representação gráfica de operações vetoriais no plano.
3.  **Resolução de Sistemas:** Implementação de métodos como a Regra de Cramer ou Eliminação de Gauss.

## 🛠️ Tecnologias

* **HTML5 / CSS3**: Interface para entrada de dados matriciais.
* **JavaScript (ES6+)**: Lógica matemática e manipulação de arrays/matrizes.
* **LaTeX (via MathJax)**: Para a renderização de fórmulas matemáticas elegantes no navegador.

## 🎓 Contexto Acadêmico

A Álgebra Linear é a linguagem por trás da inteligência artificial e do processamento de imagens. Este repositório serve como material de apoio para estudantes de Licenciatura em Matemática e interessados em ingressar na área de Tecnologia da Informação.
